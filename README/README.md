# AI Learning Coach

## Project Description
This is an AI-powered learning platform that allows students to upload PDFs, generate quizzes, summaries, and study timetables using AI.

## Features
- User Login/Register
- Workspace management
- PDF upload system
- AI quiz generation
- AI summary notes
- Timetable generator
- Saved notes and timetables

## Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express
- AI API: OpenRouter (GPT-4o-mini)
- Storage: JSON file system
